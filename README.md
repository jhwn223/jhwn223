### 🚲 따릉이 프로젝트 &nbsp;·&nbsp; 서울시 공공자전거 부족 예측

> 서울시 따릉이 대여 기록 170만 건(2025년 1월)과 기상청 날씨 데이터를 결합해
> **부족 진단 → 이동 흐름 분석 → 부족 예측** 세 단계로 풀어낸 데이터 분석 프로젝트.

- **부족 진단** — 2,000여 개 대여소의 시간별 순유출입 집계, 평일 오전 7시 출근 시간대 부족 집중 확인
- **이동 흐름(OD) 분석** — 상위 20개 이동 패턴 추출, 따릉이가 지하철역과 주거·상업 지역을 잇는 **라스트 마일** 수단임을 확인
- **부족 예측** — "시간당 3대 이상 부족" 이진 분류. 로지스틱 회귀 베이스라인 → 시차(lag) 피처와 날씨를 더한 랜덤 포레스트로 **AUC 0.66 → 0.73**
- **가설 검증** — 강수 시 부족 비율 6.9% → 4.5%로 감소, 날씨 가설 확인
- **한계도 함께 기록** — 1개월 데이터라 계절성 학습 불가, 단일 관측소로 미기후 반영 어려움, 클래스 불균형으로 정밀도 낮음

`Python` `pandas` `PyArrow` `scikit-learn`
